# HomeTheatreFacade
Developed a Home Theater Control Application in C# using the Facade Design Pattern. The project simplifies interactions between multiple subsystems such as DVD Player, Projector, Sound System, Lights, and Screen through a single unified interface, improving usability and maintainability.
